# AI E-Commerce Backend

A production-ready e-commerce backend built with Python and FastAPI.

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- Pydantic
- JWT Authentication
- Docker
- Pytest
- Swagger / OpenAPI

## Features

- User authentication
- Product management
- Categories
- Shopping cart
- Orders
- Addresses
- API validation
- Database migrations
- Automated tests
- Dockerized development environment
